Gallery Page Structure
1. Hero Section
Page title: “Gallery”
Short tagline (example: “Explore our manufacturing excellence”)
Background: factory / machinery image

2. Filter / Category Tabs (Important 🔥)
Tabs or buttons:
All
Manufacturing
Machinery
Products
Facilities
Smooth filtering (UI interaction)

3. Image Gallery Grid (Main)
Masonry / grid layout
Each Item:
Image (factory / product / process)
Hover effect:
Zoom
Overlay icon
Click → opens lightbox (full view)

4. Video Gallery (Optional Premium)
2–4 video thumbnails
Each Item:
Video preview image
Play button
Opens popup video

5. Featured Highlights Section
Large images (full-width cards)
Show:
Factory
Production line
Key machinery

6. Behind the Process (Story Section)
Small description:
“How we work”
3–4 images showing process steps

7. CTA Section
Line:
“Want to know more about our capabilities?”
Button:
Contact Us / Get Quote

8. Footer
Same global footer
