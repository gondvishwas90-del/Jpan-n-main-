Events Page Structure
1. Hero Section
Page title: “Events”
Short tagline (example: “Our presence across industry events and exhibitions”)
Background: exhibition / corporate event image

2. Upcoming Events (If applicable)
List / cards of upcoming events
Each Card:
Event name
Date
Location
Short description
“Know More” CTA

3. Past Events (Main 🔥)
Grid / list layout
Each Event Card:
Event image
Event name
Date
Location
Short 1–2 line description
“View Gallery” CTA

4. Event Detail Section (Optional Expand)
(When user clicks an event)
Inside:
Event images (gallery)
Description (what happened, participation)
Highlights (key points)

5. Exhibitions & Trade Shows
Section highlighting:
Industry expos
Trade fairs
Logos / images + short info

6. Corporate Activities
Internal events:
Team events
Training sessions
CSR activities
Images + small captions

7. Achievements / Awards (Optional)
If any awards from events
Trophy icons + short text

8. CTA Section
Line:
“Connect with us at upcoming events”
Button:
Contact Us / Enquiry

9. Footer
Same global footer
