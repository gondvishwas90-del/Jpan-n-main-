# Implementation Plan: Jpan Tubular "Annual Return" Page

This document outlines the systematic approach to building the "Annual Return" page for J pan Tubular, based on the content structure provided in `Annual Return.md`. The design will focus on statutory precision, legal clarity, and professional accessibility.

---

## Section-by-Section Analysis

### 1. Hero Section
*   **Visual Strategy**: High-end corporate/legal imagery (close-up of a signed document or a modern seal).
*   **Message**: "Annual Return: Statutory Precision & Regulatory Transparency."

### 2. Intro Section
*   **Visual Strategy**: Clean, authoritative typography defining the legal significance of annual filings.

### 3. Annual Return Listing (Main)
*   **Visual Strategy**: A systematic, table-based layout for high-density document discovery.
*   **Row Design**: Clear fiscal year labeling, filing status, and primary action triggers (View/Download).

### 4. Detailed Document View
*   **Visual Strategy**: Immersive modal featuring a technical PDF viewer optimized for legal text.

### 5. Archive / Filter
*   **Visual Strategy**: Horizontal fiscal-year discovery bar consistent with the Investor Relations ecosystem.

### 6. Compliance Note
*   **Visual Strategy**: Minimalist info-cards or a sidebar highlighting regulatory authorities and filing protocols.

### 7. CTA Section
*   **Visual Strategy**: Professional banner with a "Connect with Compliance" primary action.
