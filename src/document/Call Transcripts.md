Call Transcripts Page Structure
1. Hero Section
Page title: “Call Transcripts”
Short tagline (example: “Read detailed transcripts of investor and analyst calls”)
Background: corporate / meeting / document image

2. Intro Section
3–4 lines:
Purpose of transcripts
Written record for investor transparency

3. Transcripts Listing (Main 🔥)
List / table layout
Each Row/Card:
Call title (example: “Earnings Call Transcript – Q2 2025”)
Date
Type (Earnings Call / Investor Call)
Short description (optional)
“View” button
“Download PDF” button

4. Transcript Detail View (On Click)
Inside:
Title
Date
Call type
Full transcript text (well formatted)
Download option

5. Archive / Filter
Filter by:
Year
Quarter
Call type
Search option

6. Related Recordings (Optional 🔥)
Link to:
Call Audio Recordings
Small cards with “Listen Now” CTA

7. CTA Section
Line:
“Stay updated with our investor communications”
Button:
Contact Us

8. Footer
Same global footer
