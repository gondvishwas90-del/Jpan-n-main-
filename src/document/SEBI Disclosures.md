SEBI Disclosures Page Structure
1. Hero Section
Page title: “SEBI Disclosures”
Short tagline (example: “Regulatory disclosures as per SEBI guidelines”)
Background: corporate / legal / finance image

2. Intro Section
3–4 lines:
About SEBI compliance
Transparency & regulatory responsibility

3. Disclosures Listing (Main 🔥)
Table / list layout
Each Row/Card:
Disclosure title (example: “Regulation 30 Disclosure – 2025”)
Date
Category (optional)
Short description (1 line)
“View” button
“Download PDF” button

4. Disclosure Detail View (On Click)
Inside:
Title
Date
Category
Full document (embedded PDF)
Download option

5. Categories / Filter (Important)
Filter by:
Year
Regulation type (Reg 30, Reg 33, etc.)
Search option

6. Compliance Statement (Optional)
Short section:
Adherence to SEBI norms
Disclosure policy

7. CTA Section
Line:
“For more regulatory information, contact us”
Button:
Contact Us

8. Footer
Same global footer
