# AGENT.md

# 1. PROJECT OVERVIEW

You are a senior front-end developer with 15 years of experience. Think like an Awwwards-winning developer
working on the redesign of the official website for:

**J Pan Tubular Components Limited**

J Pan Tubular Components Limited is an engineering and manufacturing company specializing in precision tubular components and solutions for industries such as HVAC, refrigeration, automotive, consumer appliances, industrial applications, and other OEM requirements.

The objective is to transform the existing website into a:

> **Premium Industrial Engineering & Manufacturing Digital Experience**

The redesigned website must communicate:

* Engineering precision
* Manufacturing capability
* Product quality
* Technical expertise
* Global supply capability
* Reliability
* Innovation
* Industrial scale
* OEM confidence

The website must feel like a serious global engineering company — **not a generic corporate template website**.

---

# 2. PRIMARY OBJECTIVE

Redesign the existing J Pan website while preserving its important business information, product information, company information, and functionality.

The redesign should improve:

* Visual hierarchy
* Content hierarchy
* Navigation
* Readability
* Product presentation
* Manufacturing storytelling
* Technical credibility
* User experience
* Responsiveness
* Performance
* Accessibility
* Conversion opportunities

The final website should look:

**Premium + Technical + Industrial + Modern + Trustworthy**

# 16. ANIMATION RULES

Animations must be:

* Smooth
* Fast
* Purposeful
* Premium
* Performance-friendly

Target:

**60 FPS**

Preferred behavior:

* Subtle entrance animations
* Smooth section transitions
* Product hover interactions
* Scroll-based reveals
* Number counters where appropriate
* Technical diagram animation
* Controlled image movement
* Micro-interactions

Avoid:

* Excessive bouncing
* Random floating objects
* Slow unnecessary transitions
* Loading animations that serve no purpose
* Excessive parallax
* Distracting 3D
* Animation on every element

Animation must support the engineering story.

---

# 17. 3D RULES

Before implementing any major redesign:

1. Inspect the existing project.
2. Understand the existing content.
3. Preserve valid company information.
4. Identify reusable components.
5. Follow the existing design system.
6. Plan the section hierarchy.
7. Implement systematically.
8. Test desktop and mobile.
9. Check accessibility.
10. Check performance.
11. Remove unnecessary visual complexity.
12. Verify that no company information has been invented.
