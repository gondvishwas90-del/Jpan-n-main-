Annual Reports Page Structure
1. Hero Section
Page title: “Annual Reports”
Short tagline (example: “Access our yearly financial and performance reports”)
Background: corporate / business report image

2. Intro Section
3–4 lines:
About annual reports
Transparency + company performance overview

3. Reports Listing (Main 🔥)
Grid / list layout
Each Report Card:
Year (big highlight)
Report title (example: “Annual Report 2025”)
Short 1-line description
“View” button
“Download PDF” button

4. Detailed Report View (On Click)
Inside:
Title
Year
Summary (optional)
Embedded PDF viewer
Download option

5. Archive / Filter
Filter by:
Year
Search option

6. Financial Highlights (Optional)
Key stats for selected year:
Revenue
Growth
Key achievements

7. Investor Information (Optional)
Notes / disclosures
Policies link

8. CTA Section
Line:
“Explore our performance and growth journey”
Button:
Contact Us

9. Footer
Same global footer
