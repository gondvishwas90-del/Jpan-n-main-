# Implementation Plan: Jpan Tubular "Policies" Page

This document outlines the systematic approach to building the "Policies" page for J pan Tubular, based on the content structure provided in `Policies.md`. The design will focus on institutional trust, regulatory clarity, and streamlined document access.

---

## Section-by-Section Analysis

### 1. Hero Section
*   **Visual Strategy**: Minimalist, high-authority corporate imagery (architectural lines, legal library textures, or frosted glass office partitions).
*   **Message**: "Policies: Our Governance & Ethical Framework."

### 2. Intro Section
*   **Visual Strategy**: Elegant typography emphasizing J pan's commitment to transparency, ethical conduct, and statutory adherence.

### 3. Categories / Filter Bar
*   **Visual Strategy**: A sticky, high-precision navigation bar allowing users to toggle between Governance, HR, and Compliance categories. Includes a real-time search engine.

### 4. Policies Listing (Main)
*   **Visual Strategy**: A high-density grid of document cards. Each card features an icon-based identification (Governance/HR/Compliance), a clear title, and primary actions (View/Download).

### 5. Key Policies Highlight
*   **Visual Strategy**: An immersive, high-contrast section featuring 3-4 cornerstone policies (e.g., Code of Conduct) with brief contextual summaries.

### 6. Policy Detail View
*   **Visual Strategy**: An immersive modal with a professional PDF document viewer, optimized for high-fidelity legal document reading.

### 7. CTA Section
*   **Visual Strategy**: A clean, professional conversion strip with a "Request Policy Clarification" action.
